      1. Get everything1. Tout récupérer

      The script detects the distribution (rpm, deb or arch based), imports the signing key and registers every package repository of the universe. A repository already set up on its own (ex: /etc/yum.repos.d/libutils.repo) is kept and skipped.Le script détecte la distribution (base rpm, deb ou arch), importe la clé de signature et déclare tous les dépôts de paquets de l'univers. Un dépôt déjà configuré seul (ex : /etc/yum.repos.d/libutils.repo) est gardé et ignoré.

      curl -fsSL https://tsukini22.github.io/my-universe/install.sh | bash -s
      wget -qO- https://tsukini22.github.io/my-universe/install.sh | bash -s
      ArgumentArgumentEffectEffet
      --only a,bRegister only these packagesNe déclarer que ces paquets
      --no-sudoRun without sudo (the script must already run as root)Lancer sans sudo (le script doit déjà tourner en root)
      --dry-runPrint what would be done, change nothingAfficher ce qui serait fait, sans rien changer
      -h, --helpDisplay the usageAfficher l'aide

      With the CLIAvec la CLI

      The universe command of the repository does the same, then installs, updates and describes the packages (dnf info style).La commande universe du dépôt fait la même chose, puis installe, met à jour et décrit les paquets (façon dnf info).

      git clone https://github.com/TsukiNi22/my-universe.git && cd my-universe
./universe setup                    # register the package repositories
./universe install all --hand-made  # install every hand-made package (--pre: pre-release)
./universe info libutils            # versions, formats, sub-packages, installed or not
./universe outdated                 # installed vs latest version
./universe update                   # upgrade the installed universe packages

      3. Repository files3. Fichiers du dépôt

      Everything is generated from the package repositories of each project: my-universe only points to them, nothing is copied.Tout est généré depuis les dépôts de paquets de chaque projet : my-universe ne fait que pointer vers eux, rien n'est copié.

      FileFichierContentContenu
      universe.repoEvery rpm repository, for /etc/yum.repos.d/Tous les dépôts rpm, pour /etc/yum.repos.d/
      universe.listEvery deb repository, for /etc/apt/sources.list.d/ (key in /etc/apt/keyrings/universe.gpg)Tous les dépôts deb, pour /etc/apt/sources.list.d/ (clé dans /etc/apt/keyrings/universe.gpg)
      universe.confEvery pacman repository, to append to /etc/pacman.confTous les dépôts pacman, à ajouter à /etc/pacman.conf
      install.shThe setup script aboveLe script d'installation ci-dessus
